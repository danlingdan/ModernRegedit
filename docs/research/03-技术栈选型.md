## 注册表访问 API

**Win32(advapi32.dll / winreg.h)能力全集**:`RegOpenKeyEx`、`RegEnumKeyEx`、`RegQueryValueEx`、`RegCreateKeyEx`、`RegDeleteKey`(仅删空键)/`RegDeleteTree`(递归删)、`RegNotifyChangeKeyValue`、`RegConnectRegistry`(远程)、`RegLoadKey`/`RegUnloadKey`(离线蜂巢挂载)、`RegSaveKey`、`RegCreateKeyTransacted`(KTM 事务)。

**C# Microsoft.Win32(RegistryKey,.NET 10)**:
- 支持 WOW64 视图:`OpenBaseKey(hive, RegistryView.Registry32/Registry64)`,KEY_WOW64_32KEY/64KEY 语义;
- 支持远程(`OpenRemoteBaseKey`)、ACL、`GetValueKind` 与事务外全部常规操作;
- 不支持事务(`RegCreateKeyTransacted`)与变更通知(`RegNotifyChangeKeyValue`),均需 P/Invoke;键被删除后通知即停止,需重新注册。

**Rust 绑定**:winreg 0.56(crates.io,2026-03 更新)覆盖基本操作 + 迭代器,`transactions` feature 提供 KTM 事务;windows-rs(微软官方)提供全部原始 API。

**本项目方案**:C# `Microsoft.Win32` 打底,为事务、变更通知、`RegLoadKey`、`RegConnectRegistry` 高级参数写薄 P/Invoke 层(`RegistryNative` 静态类,约 300–500 行,pinvoke.net 样例齐备);句柄用 `SafeRegistryHandle` 包装;MVVM 分层,ViewModel 不引用 `Microsoft.Win32`。

## 高性能浏览关键技术

1. **树形懒加载 + UI 虚拟化**:不一次性枚举全树,展开时才异步 `RegEnumKeyEx` 枚举子键,先插 dummy 子节点保证展开箭头(WPF:`VirtualizingStackPanel.IsVirtualizing="True"` + `VirtualizationMode="Recycling"`)。HKCR 根下可达数千子键。
2. **异步枚举**:`Task.Run` + 每线程独立 `RegistryKey` 句柄(非线程安全),结果经 `IProgress<T>`/`Dispatcher` 回 UI。
3. **全库搜索并行化**:按根键(HKLM/HKCU/HKCR/HKU/HKCC)× 顶层分支切片,`Parallel.ForEach` 限并发(`MaxDegreeOfParallelism = 2×核数`),支持 `CancellationToken` 取消;结果流式分批(每 100 条)刷新 UI,首屏结果 <100ms 即展示;深度优先,跳过无权限键。
4. **防抖与缓存**:搜索框 250–300ms 防抖;子键名 LRU 缓存(容量约 1 万条);`RegNotifyChangeKeyValue`(`REG_NOTIFY_CHANGE_NAME` 等 filter)监视当前展开键,变更时精准失效缓存并重注册。
5. **值列表**:单键值数量通常 < 数百,虚拟化作保底。

## 打包、分发与签名

| 方式 | 优点 | 缺点 | 体积 |
|---|---|---|---|
| 单文件绿色版(self-contained single-file, zip) | 免安装,可进 WinPE/U 盘 | 无自动更新、无包标识 | ~80–90MB(trim 后 ~40MB) |
| MSIX | 干净卸载、增量更新、Store 上架、包标识 API | 要求打包签名;WinUI 3 默认此路 | — |
| Inno Setup / NSIS | 传统企业环境友好,体积小 | 无自动更新、无包标识 | — |

- **winget**:向 microsoft/winget-pkgs 开源仓库提交 manifest PR(`wingetcreate` 工具生成),社区审核后用户可用 `winget install`,零成本。
- **代码签名(2025–2026 行情)**:OV — SSL.com $129/年(5 年期折合 $96.75/年)、Sectigo 约 $220+/年(转售渠道低至 ~$80–226/年);EV — $249–453/年(SSL.com $249 起、Sectigo EV $279–453),EV 即时消除 SmartScreen 警告,需硬件令牌。
