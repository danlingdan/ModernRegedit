# 1.0.1 优化审计

2026-10-14。范围：维护版本的功能、UI、数据完整性和预发布验证。

| 区域 | 发现 | 落地 |
|---|---|---|
| 工作区 | 单行工具栏挤压地址栏；常用操作藏在右键菜单 | 导航、命令分层；命令溢出菜单；窄窗口收窄树与搜索框 |
| 值列表 | 无本键筛选与列排序；长名称无法截断 | 名称/类型/数据筛选、排序、计数；行内容拉伸、名称省略 |
| 撤销 | 空元组被当成已有值；50 层栈丢弃最新项；使用当前视图 | 按执行顺序生成逆操作；保留最新 50 项；记录原始视图 |
| 注册表 | 创建键漏传 WOW64 标志；长值名枚举失败 | 统一视图标志；16,384 字符名称缓冲；数据缓冲重试 |
| 导入 | 损坏数字静默变零；续行残留反斜杠；重复语句按初始状态规划 | 解析失败定位；连续续行；按文件顺序维护键值状态；每键一次读取 |
| 导出 | 跳过读失败的子键仍生成文件 | 完整读取后移动临时文件；读失败向界面报告 |
| 搜索 | 队列批次可能晚于完成状态；默认值名与普通名称混用 | 每分片等待一批呈现；关闭时失效；原始值名与键命中标志分开 |
| 写入 | 同步等待提权助手；包身份依赖环境变量 | 后台等待、写入期间串行、Windows API 查询包身份、清理助手文件 |
| 复制 | 二进制只复制列表预览的前 16 字节 | 从原始数据生成完整剪贴板文本 |
| 主题 | 浅色标题栏白字；对话框跟随系统主题 | 标题栏、按钮、所有对话框跟随应用主题 |
| 会话 | 设置文件直接覆盖；收藏夹 null 影响启动 | 临时文件原子替换、加载时校验 |
