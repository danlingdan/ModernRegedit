# UI 全面优化与基础功能补全

v1.0.0 发布后的整体走查（2026-10-13）：对照 PLAN §4 与 [04-UI设计方向.md](04-UI设计方向.md)，列出差距、核实实现 API、给出执行清单。

## API 核实（官方文档）

| API | 结论 |
|---|---|
| Window.ExtendsContentIntoTitleBar | 必须代码设置（XAML 会报错）；设置后系统绘制标题栏隐藏，默认拖拽区全宽 |
| Window.SetTitleBar(element) | 传非交互元素即可，无需 InputNonClientPointerSource（仅标题栏含交互控件时才需要） |
| AppWindow.TitleBar.PreferredHeightOption | Tall=48px；须在 ExtendsContentIntoTitleBar=true 之后设置，否则抛异常 |
| 非激活态 | Activated 事件 + WindowCaptionForeground / WindowCaptionForegroundDisabled 主题资源 |
| 提权后标题栏配色 | ExtendsContentIntoTitleBar=true 时按钮透明、跟随应用主题，原 ApplyTitleBarTheme 手工配色可整体删除 |
| InfoBar | Microsoft.UI.Xaml.Controls.InfoBar，Severity=Informational/Success/Warning/Error，IsOpen/IsClosable，WASDK 1.1 起稳定 |
| ListView 紧凑密度 | ItemContainerStyle 覆盖 MinHeight=32；默认 ListViewItem MinHeight 40 |

来源：https://learn.microsoft.com/windows/apps/develop/title-bar ；https://learn.microsoft.com/windows/apps/develop/ui/controls/infobar

## 决策

- **多标签页不做**：线框图有 TabView，但属 v1.1 级架构改动（每标签独立树/历史/搜索），与本轮"基础补全"不同类，列入 v1.1。
- **面包屑/地址栏自动补全不做**：地址栏直达已覆盖"定位慢"对策，补全列入 v1.1。
- 提交序列见下表，一个功能一个提交，每个提交构建+部署+UIA 验证。
