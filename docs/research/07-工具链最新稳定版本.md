## 核实依据

### 1. .NET SDK
- 2026-09-08 服务更新:Runtime 10.0.12 + SDK 10.0.401(4xx band)/ 10.0.112(1xx)/ 10.0.303(3xx)。
- 支持期限:.NET 10(2025-11-11 发布)为 LTS,支持至 2028 年 11 月。.NET 8 于 2026-11-10 EOL(最后安全补丁 8.0.31);.NET 9(STS)已于 2026-05 停止支持。
- 截至 2026-10-12:.NET 11 为 RC(11.0.0-rc.1),GA 定于 2026-11-10~13 .NET Conf 2026,STS 生命周期 18 个月,非 LTS。

### 2. Windows App SDK / WinUI 模板
- Stable 频道最新 2.5.1(2026-09-16);NuGet:Microsoft.WindowsAppSDK 2.5.1、Microsoft.WindowsAppSDK.Runtime 2.5.1。2.x 线生命周期至 2027-04-29;1.8 已转维护(至 2026-09-24)。
- 官方 CLI 模板包:`dotnet new install Microsoft.WindowsAppSDK.WinUI.CSharp.Templates`,提供 winui / winui-navview / winui-tabview / winui-mvvm 及 item 模板(devblogs 2026-05-12)。包仍为 0.0.6-alpha 预览;模板默认引用 Microsoft.Windows.SDK.BuildTools.WinApp,可直接 `dotnet run` 启动已打包应用。未查到"Taewi22 模板包"官方对应;VS 内模板随"Windows Application Development"workload 提供;社区替代为 VijayAnand.WinUITemplates(稳定)。

### 3. Visual Studio
- VS 2026(v18)于 2025-11-11 GA,当前稳定版 18.10.3(2026-09-29),每月更新;与 VS 2022 可并存。VS 2022 17.14(2025-05 GA)维护中。
- WinUI 3 所需 workload:".NET 桌面开发" + "Windows Application Development"(WinUI 模板、MSIX 打包工具、单项目 MSIX);VS 2026 内置 .NET SDK 10.0.401。

### 4. Windows SDK
- 最新稳定 10.0.28000.2705(2026-08),面向 Windows 11 26H1 及更早;release notes 已出现 28000.2957(2026-09 底),下载页仍列 2705。VS 2026 安装器随附 26100 与 28000 servicing 版本。

### 5. NuGet 包
- CommunityToolkit.Mvvm 8.4.2(2026-03-25);8.4.0 在 .NET 10 默认设置下编译失败(CommunityToolkit/dotnet#1139)。
- Microsoft.Windows.CsWin32 0.3.347(2026-10 初);微软文档(2026-07-22 更新)定为 Windows 桌面应用推荐源生成器,源生成用法(NativeMethods.txt)不变。
- CommunityToolkit.WinUI.*:稳定线 8.2.251219(2025-12-19,对齐 WinAppSDK 1.8),Extensions、Media、Triggers、Converters、Animations、Helpers、Controls.SettingsControls、Controls.TokenizingTextBox 等同线;Labs 实验线 8.3.260211-preview1(2026-02);8.x 无独立"Tokens"包。Toolkit 未正式标注兼容 WASDK 2.5.1。

### 6. VS Code 的 WinUI 3 开发现状
- 语言/调试:C# 扩展(开源)+ C# Dev Kit(官方,专有许可)。
- 无微软官方 WinUI XAML LSP/IntelliSense 扩展(MAUI 扩展仅面向 MAUI;donjayamanne.xaml 仅语法高亮)。推荐 WinDev Helper(alvinashcraft.windev-helper,4.0,2026-08-14):WCT 维护者开发,基于微软 winapp CLI(Microsoft.WinAppCli),提供可编辑 XAML 设计器(HTML/CSS 近似)+ Windows 原生预览、F5 调试、MSIX 打包/签名(含 Azure Trusted Signing)、Store 直发、模板与 manifest 工具。
- 纯 CLI + VS Code 可行:dotnet new 官方模板 + `dotnet run`(winapp 打包运行)+ winapp pack/sign + Store 发布均已打通。
- 缺口(官方 roadmap):XAML IntelliSense 与 XAML Hot Reload 未支持(计划中);MSIX 打包应用暂不支持调试器附加;设计器为近似渲染,第三方控件显示为占位符;高级调试场景需 Visual Studio。

### 7. Microsoft Store 开发者账户
- 个人:2025-09-12 起注册免费(原 $19)。企业:2026-05-07 起 $99 注册费取消。个人与企业注册均 0 费用、无年费。
