# UI 设计方向

ModernRegedit 的 UI 设计规范调研(2026-10-12):Fluent 2 设计语言、Win11 regedit 现状、改造方向、数据密集界面规范、设计 Token 与控件库。

## Fluent 2 / Windows 11 设计语言

- **材质**:Mica 不透明,采样一次桌面壁纸主色调、开销极低,自带激活/失焦两态,用于主窗口底层;Acrylic 半透明磨砂,仅用于瞬态表面(弹出层、右键菜单、flyout、命令面板);Smoke 为模态对话框压暗遮罩。
- **圆角**:窗口与浮层 8px;按钮、输入框、列表项等控件 4px;列表选中高亮可用全圆角胶囊(999px)。
- **字体**:Segoe UI Variable,Type Ramp 见下文设计 Token 节。
- **图标**:Segoe Fluent Icons,系统内置约 1500+ glyph;更丰富场景补充开源 Fluent UI System Icons。
- **亮暗主题**:全部颜色为 mode-aware 令牌,跟随系统深浅模式;Windows 交互态越交互越亮(hover→selected 递增亮度);焦点态不改填充色,用 2px 外描边区分键盘操作。
- **颜色体系**:Neutral(中性灰阶,表面/文字)、Shared(语义色:红=危险、黄=警告、绿=成功)、Brand(仅用于选中态、CTA、焦点)。

## 经典 regedit 与 Win11 自带 regedit 现状

经典布局:菜单栏 + 工具栏(仅收藏夹下拉)+ 可编辑地址栏 + 左侧键树 + 右侧值列表(名称/类型/数据)+ 状态栏(当前路径)。核心交互:双击值弹编辑对话框、Ctrl+F 模态查找(单结果逐个跳转)、收藏夹、导出 .reg。

Win11 自带 regedit 现状(截至 2026):

- 22H2 Moment 2(KB5022913,2023-02)加入带下拉历史与自动补全的地址栏、命令行参数(如跳转指定键)、改进的导入/导出;
- 整体仍为 Win32 老控件:无深色模式、无标签页、无扁平右键菜单;
- 微软设计负责人 Marcus Ash(2026-03)确认 legacy UI 深色模式在推进中,regedit 在计划中但无时间表;新的"运行"对话框已用 WinUI 3 重做。

结论:官方仅补丁式现代化,原生 Fluent 2 的第三方注册表编辑器存在视觉代差空间。

## 现代化改造方向

1. **多标签页**(WinUI TabView):每个标签记住独立路径与选中值;
2. **命令面板**(Ctrl+K / Ctrl+Shift+P):Acrylic 弹层,跳转键路径、执行命令、搜索值;
3. **面包屑地址栏**:可编辑路径 + 每级下拉(同级键切换)+ 历史前进/后退;
4. **行内编辑**:F2 直接在值列表编辑;二进制保留专门十六进制网格编辑器;
5. **差异对比视图**:两个键子树 / 快照前后 diff,绿=新增、红=删除、黄=修改;
6. **书签/收藏侧栏**:统一收纳收藏键、历史、搜索结果;
7. **搜索结果面板**:Ctrl+Shift+F 全量搜索为非模态停靠面板,分页/虚拟滚动、点击定位、支持正则;
8. **右键菜单扁平化**:Win11 风格 Acrylic 菜单;危险操作(删除)红色语义色 + 二次确认;
9. **撤销/重做与操作日志**:写操作可回滚。

## 数据密集型界面规范

- **密度**:树与列表默认行高 32px,紧凑模式 28px;单元格垂直居中,内边距 8–12px。
- **值类型视觉区分**(图标 + 颜色双编码,类型列同步显示文字):REG_SZ "abc" 文本图标(蓝)、REG_DWORD "0x32" 数字图标(绿)、REG_QWORD 同系(青)、REG_BINARY "01" 图标(紫)、REG_MULTI_SZ 多行图标(橙)、REG_EXPAND_SZ 可展开图标(棕)、REG_NONE/未知灰色问号。
- **长文本截断**:数据列单行截断 + 悬停 tooltip 完整内容;REG_BINARY 显示前 N 字节十六进制 + "…"。
- **空状态**:键无值时列表中央显示图标 + "此键没有值,右键新建"引导。
- **错误提示**:删除/修改失败用 InfoBar(页内横幅);破坏性操作(删除键)用 ContentDialog 红色主按钮二次确认并显示完整路径。
- **性能感**:树与列表虚拟化,万级值不卡顿;搜索进行中显示进度而非冻结。

## 无障碍与多语言

- **键盘全可达**:树/列表/地址栏 Tab 环游,方向键树内导航,F6 区域切换,所有命令有快捷键;焦点可见(2px 描边)。
- **对比度**:正文 ≥ 4.5:1,大字/图形 ≥ 3:1;支持 Windows 高对比度主题与 Contrast Themes API。
- **屏幕阅读器**:UIA AutomationPeer 全覆盖,值编辑控件暴露类型与原始数据。
- **多语言**:文案走资源文件(resw),预留 30% 文本膨胀;CJK 字体回退 Microsoft YaHei UI;布局支持 RTL 镜像。

## 设计 Token

**颜色(亮色 / 暗色,对应 WinUI ThemeDictionaries)**:

| Token | Light | Dark | 用途 |
|---|---|---|---|
| WindowBg (Mica) | #F3F3F3 + 壁纸染色 | #202020 + 壁纸染色 | 窗口基底 |
| LayerBg | #FFFFFF | #2B2B2B | 列表/内容层卡片 |
| CardBg / ListAlt | #F9F9F9 | #272727 | 斑马纹、悬停 |
| TextPrimary | #1A1A1A | #FFFFFF | 主文字 |
| TextSecondary | #5D5D5D | #C8C8C8 | 辅助文字 |
| Divider | #E0E0E0 | #383838 | 分隔线 |
| Accent | #0067C0 | #4CC2FF | 选中、链接、CTA |
| Success/Warning/Danger | #0F7B0F/#9D5D00/#C42B1C | #6CCB5F/#FCE100/#FF99A4 | diff/危险操作 |
| SubtleFill (hover/selected) | 8%/12% 黑 | 8%/12% 白 | 交互态 |

**字体(Type Ramp)**:Segoe UI Variable;Caption 12/16px(状态栏、列副文本)、Body 14/20px 默认、Body Strong 14/20px(列头)、Body Large 18/24px、Subtitle 20/28px(页头)、Title 28/36px;等宽场景(数据/路径)Consolas 或 Cascadia Mono 13px。

**间距**:4px 基准网格;面板内边距 12px,区块间距 8/12/16,列表行内边距 8px 水平。

## 图标与控件库

- **图标**:首选系统 Segoe Fluent Icons(零分发成本、与 Win11 一致);不足处用 Fluent UI System Icons(microsoft/fluentui-system-icons,MIT)补齐;值类型图标用自定义单色 glyph 匹配语义配色。
- **控件库**:WinUI 3(Windows App SDK)+ Windows Community Toolkit(原生 Mica/TabView/InfoBar/CommandBar/TeachingTip,Files 与 DevToys 同栈);备选 WPF + WPF-UI、Avalonia + Semi.Avalonia/FluentAvalonia。
- **原型/设计稿**:Figma 安装 Fluent 2 官方 UI Kit 与 Segoe Fluent Icons Search 插件。
