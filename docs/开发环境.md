# 开发环境

> 本机实测，2026-10-12。版本依据见 [research/07-工具链最新稳定版本.md](research/07-工具链最新稳定版本.md)。
> 版本策略：只用最新稳定版，不用 preview / RC / alpha。

## 结论

- 工具链就绪，均为最新稳定版：.NET SDK 10.0.401、VS 2026 Enterprise 18.10（含 WinUI 模板）、git 2.56、gh 2.102（已登录）、winget 1.29。
- Windows SDK：26100 与 28000 并存；项目用 28000，26100 保留作回退（约 1.2 GB，side-by-side 安装互不干扰）。
- 开发者模式已启用，MSIX 可直接部署调试。
- 主 IDE 为 VS 2026；VS Code 只作编辑器（无 XAML 智能感知与热重载）。
- 不需要：node、WASDK Runtime 单独安装（由 NuGet / 商店携带）。

## 环境自检

```bash
dotnet --list-sdks
ls "C:/Program Files (x86)/Windows Kits/10/Include"
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\AppModelUnlock" //v AllowDevelopmentWithoutDevLicense   # 1 = 开发者模式开
```

## 常用命令

```bash
dotnet build src/ModernRegedit -c Release
# sideload 包：/p:UapAppxPackageBuildMode=SideloadOnly /p:AppxBundle=Never → 产物在 AppPackages/
# 商店包：  /p:UapAppxPackageBuildMode=StoreUpload
dotnet format
dotnet test
```

- 日常开发：VS 2026 打开解决方案 F5（部署、调试、XAML 热重载）。
- Git Bash 中 Windows 命令的开关写双斜杠：`reg query ... //v 名称`。
