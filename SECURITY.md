# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| latest 0.x release | Yes |
| older releases | No |

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/danlingdan/ModernRegedit/security/advisories/new). Do not open a public issue.

Include: app version, Windows build, steps to reproduce, impact.

Initial response within 7 days.
